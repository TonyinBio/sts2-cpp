# Concrete cross-system evidence cases

All cases below are required planning obligations, with new captures and C++
comparisons **pending**. Route anchors identify stored state for inspection, not
an executable alternate-branch fixture or a native public golden. Use independent
native reachable setups; never assume arbitrary edited snapshots can be imported.

Semantic anchors in this table refer to sections of
[shared-capabilities.md](../victory-semantics/shared-capabilities.md), which holds
native file/line references and is clarified by the linked lifetime records.
Individual model branches remain in [models.json](models.json).

For each matrix row, preserve fixture setup and native operation trace in addition
to public input boundaries. If a hook ordering difference is invisible at one stop,
use a downstream observer/branch that distinguishes it rather than declaring equality
from final HP alone. Internal traces are privileged evidence, not new public fields.

Fixed outputs documented in the source audit (for example Archaic Tooth, Momentum,
Nimble/Swift, finite Bowlbug alternatives and Architect) need the same case discipline.
An implementation may factor their shared capabilities; it cannot replace them with
one recorded effect. Broad random-pool membership alone does not require every
additional effect at this milestone.
